Quand la demande de voyage se cherche-t-elle ?

Le trafic passagers est publié une fois par an, avec près d'un an de retard. La recherche est visible tout de suite. Ce tableau de bord mesure le temps qui les sépare, marché par marché, pour savoir quand engager un budget d'acquisition.

Profils saisonniers, fenêtre 2015-2019

Les douze valeurs mensuelles moyennes de chaque série, ramenées à une moyenne de 1. Terracotta : la recherche dans le marché. Sombre : le trafic sur la route. Le point marque le pic de chaque courbe, et c'est l'écart entre ces deux points que mesure l'indicateur de tête. Passer par le profil moyen élimine la tendance, le bruit d'une année isolée et la reprise post-pandémie.

Les trois mesures, côte à côte

L'écart des pics est l'indicateur de tête. L'écart des centres de gravité prend toute la masse de la saison et pas seulement son sommet : quand les deux se rejoignent, la mesure tient ; quand ils divergent, le profil est plat ou bimodal et la ligne est marquée peu fiable. La corrélation croisée est conservée pour transparence, bien qu'elle échoue sur les profils bimodaux.
